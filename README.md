 Prism


  A real-time music visualizer with 10 shader-based visual modes,
  dynamic album palette extraction, and full responsiveness across desktop and mobile.

## Visual modes

| Mode | Description |
|---|---|
| `MILKDROP` | 3-level domain warp + IFS fractal folds + beat shockwaves |
| `PSYCHO` | Kaleidoscopic symmetry folds + cascaded domain warp + HSV cycling |
| `SMOKE` | 4-layer volumetric smoke with simulated internal lighting |
| `PLASMA` | FBM noise warp + audio-reactive rings |
| `TUNNEL` | Infinite depth fly-through — speed driven by audio energy |
| `FRACTAL` | Julia set with live parameter morphing on beat |
| `LISSAJOUS` | Multi-curve parametric figures with glow |
| `MELANCHOLY` | Slow warped streaks + liquid pooling — ambient mode |
| `SCOPE` | Classic waveform oscilloscope |
| `RIPPLE` | Beat-driven ripple propagation from center |

---

## Features

- **Dynamic palette** — extracts dominant colors from album art, animates smooth transitions between palettes
- **Real-time audio analysis** — kick detection, pulse, energy, BPM phase, anticipation, flash events
- **Fully responsive** — aspect-correct GLSL UVs, works on mobile and desktop
- **Post-processing** — bloom pass (blur H + blur V + composite), crossfade between modes
- **iTunes Search API** — track lookup and album art integration
- **Deployed on Vercel** — no build step, pure ES modules
